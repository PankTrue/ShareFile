# ShareFile для macOS

Очередь показывает скорость и примерное оставшееся время для текущего файла или папки, общий процент по байтам и число готовых объектов подборки. Завершённые объекты учитываются вместе с оставшимися объектами своей подборки; старые завершённые подборки не влияют на новую. Скорость рассчитывается по подтверждениям сервера за последние 10 секунд, обновляется раз в секунду и заново оценивается после паузы. Восстановленные через HEAD байты не считаются новой передачей. Во время паузы или ошибки оценка времени скрывается; создание ссылки отображается отдельно.

Нативное приложение SwiftUI/AppKit и Finder Service, общее ядро передачи на Go. Backend и React UI не требуют изменений. Сборка содержит UI и Go helper для Apple Silicon и Intel; минимальная версия macOS — 13.0. Локально проверяется macOS 27.0.1 на Apple Silicon. Минимальная версия и Intel пока подтверждены компиляцией, запуск на этих системах требует отдельной проверки.

## Установка

Готовый пакет: `clients/macos/build/ShareFile-macOS-universal.zip`. Распакуйте его и запустите `Install.command`: приложение копируется в `~/Applications/ShareFile.app` без `sudo`. Либо перенесите `ShareFile.app` в `Applications` вручную. При обновлении закройте приложение; установщик сохраняет предыдущую версию в отдельной папке.

Локальная сборка подписана ad-hoc. Для внешнего распространения нужен собственный Developer ID и notarization; в этой сборке notarization не выполняется. Если macOS блокирует запуск, используйте штатное подтверждение приложения в «Системные настройки → Конфиденциальность и безопасность». Системную защиту отключать не нужно.

Первое подключение:

1. Откройте **Настройки** и укажите публичный адрес `https://…keenetic.pro` без пути. HTTP разрешён только для разработки на loopback.
2. Нажмите **Подключить через браузер**, войдите в Web UI и подтвердите этот Mac. Приложение ожидает подтверждение до 10 минут, опрашивая API не чаще указанного интервала (минимум 12 секунд).
3. По умолчанию выбрана личная папка `Uploads`, ссылка действует 7 дней, пароль отсутствует. В настройках можно выбрать другую доступную папку с правами управляющего, срок или пароль.

Токен устройства и необязательный пароль ссылки хранятся в login Keychain. Пароль аккаунта приложение не получает. **Отключить Mac** удаляет локальный токен; для отзыва серверного разрешения удалите устройство в Web UI → Аккаунт → Устройства. Отключение аккаунта или отзыв устройства прекращает API-доступ.

## Finder и очередь

Выберите файлы или каталоги, затем **правый клик → Службы → ShareFile: Загрузить и поделиться**. По умолчанию окно ShareFile не открывается и приложение не забирает фокус: файлы загружаются в фоне, после создания ссылок они копируются в буфер обмена. Это работает и при запуске службы из закрытого приложения. Finder сразу получает управление. Если Mac ещё не подключён к хранилищу, открываются настройки подключения; выбранные файлы остаются в памяти до подтверждения.

В **Настройки → Finder и уведомления** доступны два переключателя, оба включены по умолчанию и сохраняются сразу:

- **Загружать из Finder без открытия окна** — отключите, если хотите видеть очередь при каждом вызове службы.
- **Уведомлять о загрузке и копировании ссылки** — после успешной загрузки и копирования появляется системное уведомление. Для группы файлов копируются все ссылки и отправляется одно уведомление. Если буфер обмена отклонил запись, уведомление сообщает об этом, не утверждая, что ссылка скопирована.

При первом уведомлении macOS запросит разрешение. Если уведомления запрещены в **System Settings → Notifications → ShareFile**, загрузка и копирование продолжают работать. Уведомление содержит имена файлов и результат; сами ссылки и токен устройства туда не передаются. Нажатие на уведомление открывает очередь. [Разрешение локальных уведомлений Apple](https://developer.apple.com/documentation/usernotifications/asking-permission-to-use-notifications).

Открыть окно или настройки вручную можно через значок ShareFile в строке меню. Обычный запуск приложения вручную по-прежнему показывает окно.

Если служба скрыта, включите её в **Системные настройки → Клавиатура → Сочетания клавиш → Службы → Файлы и папки**. Запуск приложения вызывает `NSUpdateDynamicServices`; после ручного перемещения приложения может потребоваться повторный вход в macOS. Регистрация службы следует [документации Apple](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/SysServices/Articles/providing.html), типы и фильтр Finder — [Services Properties](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/SysServices/Articles/properties.html).

Можно выбрать файлы кнопкой приложения или перетащить их в окно. Загружается один файл за раз, без полного чтения файла в RAM. После завершения выбранной группы ссылки копируются в буфер обмена, по одной на строку. У каждой завершённой записи есть кнопка **Ссылка**. При совпадении имени сервер добавляет суффикс; существующий файл не заменяется. Папки, пакеты приложений и другие каталоги пока не поддерживаются.

Пауза сохраняет очередь в `~/Library/Application Support/ShareFile/state.json`; после перезапуска нажмите **Продолжить**. Адрес сервера и аккаунт проверяются перед использованием старой очереди. Нельзя переключить сервер/аккаунт с непустой очередью. Файл должен остаться по исходному пути; размер, время изменения и SHA-256 выборок начала, середины и конца проверяются перед продолжением. Это защита от случайной замены источника, а не полная криптографическая проверка всего локального файла. Во время передачи проверяются размер и время изменения. Не редактируйте файл до окончания загрузки.

После обрыва сети клиент сверяет durable offset через `HEAD`. Создание загрузки использует сохранённый idempotency key; потеря ответа не создаёт второй объект. Передача использует `POST` с `X-HTTP-Method-Override: PATCH`, учитывает ограничение сервера и отправляет не более 4 MiB за запрос. Автоматические повторы ограничены; при продолжительном сбое очередь остаётся для ручного продолжения. Для отмены серверной загрузки требуется подключение того же аккаунта. Удаление завершённой записи убирает её из очереди, файл остаётся в хранилище.

Публичная ссылка возвращается сервером один раз и сохраняется в Keychain. Через значок ShareFile → **Недавние ссылки** доступны последние восемь записей с действиями **Копировать ссылку**, **Открыть ссылку** и **Отозвать ссылку**. **История ссылок…** открывает полный список с поиском по имени файла или папки, датой создания, сроком действия и отметкой отзыва. Копирование и открытие работают после перезапуска, в том числе без подключения; для отзыва нужен тот же сервер и аккаунт.

История хранит до 200 последних ссылок всех подключений; экран показывает записи текущего аккаунта. Создание новой ссылки сохраняет предыдущую запись. Очистка очереди и отключение Mac сохраняют историю. Индекс `~/Library/Application Support/ShareFile/history.json` содержит только имена, даты и ID, с правами 0600 в каталоге 0700; URL находятся только в Keychain. При вытеснении старой записи или подтверждённом отзыве её URL удаляется из Keychain. Вытеснение из локальной истории не отзывает ссылку на сервере.

Создание ссылки не повторяется автоматически: после потери ответа или завершения приложения во время создания проверьте ссылки объекта в Web UI и при необходимости отзовите неизвестную ссылку, затем создайте новую. При отказе Keychain или диска созданная ссылка остаётся доступной в текущей очереди с сообщением об ошибке сохранения истории. Ссылки, отправленные предыдущей версией и уже потерянные после её закрытия, восстановить из сервера нельзя. Если ссылка защищена паролем, передайте пароль получателю отдельно.

## Скриншот из буфера обмена

1. Запустите и подключите ShareFile. Сделайте скриншот в буфер: **Control+Command+Shift+4** (или **Control+Command+Shift+3** для всего экрана).
2. Нажмите **Command+Shift+U (⌘⇧U)** в любом приложении. Также доступны **Из буфера** в окне и **Из буфера обмена (⌘⇧U)** в строке меню.
3. Изображение загрузится в фоне; после создания публичной ссылки она заменит изображение в буфере. Уведомление приходит после копирования, если включено в настройках.

Используются текущие папка, срок и пароль ссылки (по умолчанию `Uploads`, 7 дней, без пароля). PNG и TIFF преобразуются в PNG, включая прозрачность. Максимум 25 Мп и 32 МиБ. Текст или список файлов в буфере не загружается как изображение. Клиент читает буфер только по вашему действию. Для горячей клавиши не требуется Accessibility/Input Monitoring. При конфликте сочетания используйте меню.

Ручное сохранение не нужно: служебный PNG находится в `~/Library/Application Support/ShareFile/clipboard` (каталог 0700, файл 0600). Он сохраняется при паузе/ошибке и перезапуске, удаляется после загрузки или подтверждённой отмены. Очистка касается только служебных PNG; исходные файлы пользователя остаются на месте.

## Сборка и проверки

Нужны macOS, Command Line Tools (`xcode-select --install`) и Go 1.26.8+. Внешних Swift/Go-библиотек у desktop-пакета нет.

```sh
make macos-build
make desktop-check
make macos-check
make desktop-smoke
```

При неисправном shim можно указать Go: `make GO=/absolute/path/to/go macos-build desktop-check`. Сборка universal: `clients/macos/build/ShareFile.app`. `SIGN_IDENTITY` позволяет подписать собственным Developer ID; notarization — отдельная процедура выпуска.

`desktop-check` выполняет vet и Go race tests: потерянные ответы, прерванная передача/возобновление из checkpoint, изменение источника, sparse-файл более 5 GiB, отзыв устройства, запрет redirect и автоматических повторов share. `macos-check` проверяет подписанный bundle, Finder pasteboard с несколькими Unicode-путями, запись/чтение/удаление одноразовой тестовой записи Keychain и отсутствие публичной ссылки в сохранённой очереди. Проверяются также скрытое окно при служебном запуске и повторном вызове Finder, ожидание восстановления подключения, совместимость старого JSON и сохранение новых переключателей. Keychain API выполняется вне UI-потока при обычной работе; [Apple отмечает блокирующее поведение SecItemCopyMatching](https://developer.apple.com/documentation/security/secitemcopymatching(_:_:)).

`desktop-smoke` поднимает настоящий backend на свободных loopback-портах с временным диском и аккаунтом; проверяет device pairing, загрузку через Go helper после TCP-обрыва и рестарта сервера, Unicode/пустой файл, публичную ссылку, содержимое по SHA-256 и отзыв устройства. Тот же сценарий запускает нативный Swift Model и очередь через реальный Go helper, проверяет созданные ссылки, отсутствие секретов в состоянии и показ ошибки недоступного источника. Для завершения группы проверяются порядок копирования/уведомления, отключение уведомлений без отключения копирования и ошибка буфера обмена. Копирование и доставка уведомления перехватываются тестовыми обработчиками; тест не изменяет пользовательский буфер обмена и не запрашивает разрешение уведомлений. Системные баннеры и реальный KeenDNS/KN-1811 проверяются отдельно.

`Uninstall.command` удаляет только приложение из `~/Applications`, проверяя bundle ID и запрашивая подтверждение. Очередь и Keychain сохраняются. Перед полным удалением отмените незавершённые загрузки, отключите Mac в приложении и отзовите устройство в Web UI; затем можно удалить директорию Application Support и пароль ссылки в Keychain Access. Серверные файлы установщик и удаление приложения не затрагивают.

## Загрузка каталога целиком

Перетащите каталог из Finder в окно ShareFile, выберите его кнопкой «Загрузить и поделиться» или вызовите Finder Service. В очередь добавляется одна запись на каталог: вложенные пути и пустые папки сохраняются, одинаковые имена файлов в разных подпапках остаются отдельными файлами. Общая ссылка создаётся только после завершения всего дерева. По умолчанию она действует 7 дней; срок и пароль берутся из настроек, как для файлов. Ссылки выбранной группы копируются вместе, затем приходит одно уведомление.

Пауза и перезапуск сохраняют ID папок, ключи запросов, подтверждённые позиции и завершённые файлы. Потерянный ответ создания папки восстанавливается по Idempotency-Key без дополнительного каталога. Папка с совпадающим именем в хранилище не используется как место слияния: отдельная загрузка получает новый каталог с числовым суффиксом. При изменении исходного дерева продолжение отклоняется; добавьте каталог заново. Неопределённый ответ создания общей ссылки требует проверки Web UI, автоматического повтора нет.

Лимит одного каталога — 10000 объектов и 128 компонентов относительного пути; размер сериализованного списка ограничен 8 МиБ. Символические ссылки и специальные файлы отклоняются до сетевой загрузки. Отмена незавершённого каталога отменяет его загрузки и переносит созданное дерево в обычную корзину. Удаление завершённой записи из очереди сохраняет папку в хранилище.
