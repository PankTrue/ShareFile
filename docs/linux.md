# Linux-клиент ShareFile

Отдельный клиент в `clients/linux/`: Python 3.10+, GTK 3 / PyGObject и общее Go-ядро из `clients/core/`. Интерфейс на русском. Пакеты x86_64 и ARM64 включают статическое ядро передачи; Python/GTK/libsecret устанавливаются средствами дистрибутива. Клиент работает в пользовательской графической сессии с D-Bus, X11 или Wayland.

## Установка

Ubuntu 22.04/24.04 и Debian 12/13:

```sh
sudo apt install python3 python3-gi gir1.2-gtk-3.0 libsecret-tools gnome-keyring
```

Fedora:

```sh
sudo dnf install python3 python3-gobject gtk3 libsecret gnome-keyring
```

Arch Linux:

```sh
sudo pacman -S python python-gobject gtk3 libsecret gnome-keyring
```

GNOME Keyring должен быть запущен и разблокирован в пользовательской сессии. В KDE можно использовать KWallet с включённым Secret Service API. При отсутствии/блокировке хранилища клиент сообщает об ошибке и не сохраняет токен в обычный файл. `secret-tool` получает секрет через stdin; токен и пароль не передаются в аргументах процессов.

Распакуйте пакет для своей архитектуры и запустите:

```sh
tar -xzf ShareFile-Linux-x86_64.tar.gz
cd ShareFile-Linux-x86_64
python3 install.py
```

Установка без root: приложение в `$XDG_DATA_HOME/sharefile/client` (по умолчанию `~/.local/share/sharefile/client`), launcher `~/.local/bin/sharefile`, ярлык в меню приложений. Для запуска из терминала добавьте `~/.local/bin` в `PATH` либо используйте полный путь. Опциональный автозапуск: `python3 install.py --autostart`. Обновление выполняется тем же установщиком из нового распакованного пакета.

Откройте **ShareFile** в меню приложений, укажите HTTPS-адрес и подтвердите подключение в браузере. Временный HTTP разрешён только на localhost/loopback для тестов. Пользовательские сертификаты HTTPS проверяются системным хранилищем доверия; отключения проверки TLS нет.

## Загрузка и ссылки

- Выберите несколько файлов или перетащите их в окно. По умолчанию используется личная папка `Uploads`, срок ссылки 7 дней, без пароля. В настройках доступны другая папка, 1–365 дней, бессрочная ссылка и пароль 12–256 байт UTF-8.
- Очередь показывает прогресс и поддерживает паузу, продолжение, отмену и повтор после ошибки. Для выбора папки с созданием публичной ссылки нужны права управляющего. Максимум 100 записей в очереди; завершённые записи можно удалить.
- После успешного завершения всей выбранной группы ссылки копируются вместе, по одной на строку, затем отправляется одно системное уведомление. При отказе clipboard клиент сообщает об ошибке копирования. Отключение уведомлений сохраняет копирование.
- При частичной ошибке группа не копируется как успешно завершённая. Успешные ссылки можно скопировать по отдельности; после продолжения оставшихся файлов группа будет скопирована целиком.
- Кнопка **Отозвать** отзывает известную ссылку на сервере. **Новая ссылка** требует явного подтверждения, поскольку предыдущие ссылки продолжают действовать. Управление всеми ссылками и устройствами доступно в Web UI.

Закрытие окна оставляет клиент в фоне. Повторный запуск открывает это же приложение; файлы из следующих вызовов добавляются в одну очередь через `Gtk.Application` / D-Bus. Для выхода — кнопка **Выйти** или `~/.local/bin/sharefile --quit`. В Plasma/Xfce доступен значок tray. В GNOME без расширения tray используйте ярлык приложения и уведомления.

## Файловые менеджеры

Установщик добавляет:

- Nautilus: **Scripts → ShareFile: Загрузить и поделиться**. Скрипт получает отдельные аргументы файлов; не разбирает newline-разделённую переменную окружения.
- Nemo: действие **ShareFile: Загрузить и поделиться** в контекстном меню.
- Dolphin: действие **ShareFile: Загрузить и поделиться** в меню действий/контекстном меню, в зависимости от настроек Dolphin.

После установки перезапустите файловый менеджер. Служебная отправка по умолчанию скрывает окно, копирует все ссылки и уведомляет один раз. Для первоначального подключения и ошибки восстановления подключения окно открывается. Выключение настройки тихой загрузки открывает окно при отправке. Поддерживаются локальные обычные файлы, включая пробелы и Unicode; каталоги и сетевые URI не поддерживаются.

Терминальный эквивалент:

```sh
~/.local/bin/sharefile --background -- "/путь/Отчёт.pdf" "/путь/Фото.png"
```

Форматы интеграций основаны на [GTK Application](https://docs.gtk.org/gtk3/class.Application.html), [Dolphin service menus](https://develop.kde.org/docs/apps/dolphin/service-menus/) и [Nemo Actions](https://github.com/linuxmint/nemo/blob/master/files/usr/share/nemo/actions/sample.nemo_action).

## Состояние и восстановление

Очередь: `$XDG_STATE_HOME/sharefile/state.json`, по умолчанию `~/.local/state/sharefile/state.json`; каталог 0700, файл 0600, атомарная замена с fsync. Токен, пароль и публичные URL исключены из JSON; секреты находятся в Secret Service. Неизвестная/повреждённая очередь блокирует запуск и не перезаписывается автоматически.

После перезапуска незавершённые загрузки остаются на паузе. **Продолжить** получает durable offset через HEAD; idempotency key предотвращает дубликаты при потерянном ответе создания upload. Изменение исходного файла блокирует продолжение. Размеры и смещения используют int64 без преобразования в floating point.

Если процесс завершился при создании ссылки, запись получает состояние **Проверьте ссылки в Web UI**. Автоматического повторного POST нет: сервер возвращает секрет ссылки только один раз. Публичные URL доступны в памяти до выхода; после выхода для копирования потребуется явно создать новую ссылку. Известный ID прежней ссылки сохраняется для отзыва.

## Сборка и проверки

```sh
make linux-build
make linux-check
make linux-smoke
```

Нужны Go 1.26.8 и Python 3.10+. `linux-build` можно выполнить в macOS/Linux; результат — `clients/linux/build/ShareFile-Linux-{x86_64,arm64}.tar.gz` и SHA-256. `linux-check` проверяет общее ядро, восстановление/секреты/очередь, мост и установщик. `linux-smoke` собирает backend и host-ядро, запускает настоящие передачи с временным хранилищем и тестовыми credentials.

Workflow **Linux client** настроен для запуска на Ubuntu 24.04: протокол и smoke, GTK под Xvfb/D-Bus, настоящий Secret Service, clipboard, установщик и сборка обоих пакетов. GTK-проверки включаются отдельно переменной SHAREFILE_REQUIRE_GTK, обычный linux-check их пропускает. Для ручного повторения GTK-проверок в Linux:

```sh
sudo apt install xvfb dbus-x11 desktop-file-utils
make linux-smoke
SHAREFILE_REQUIRE_GTK=1 SHAREFILE_HELPER="$PWD/clients/linux/build/sharefile-client-host" \
  dbus-run-session -- xvfb-run -a python3 -m unittest discover -s clients/linux/tests -p test_gtk.py -v
```

Проверки, выполненные на текущем macOS-хосте, фиксируются в [validation.md](validation.md). Проверка GTK в CI не заменяет ручную проверку Nautilus/Nemo/Dolphin, tray, уведомлений и Wayland на целевом desktop. ARM64-пакет собирается отдельно; его запуск на Linux ARM64 требует соответствующего устройства.

## Удаление

```sh
~/.local/share/sharefile/client/uninstall.sh
```

При переопределённом XDG_DATA_HOME используйте соответствующий путь. Удаление останавливает клиент, удаляет launcher, desktop/tray и действия файловых менеджеров, сохраняя очередь и системные секреты. Чтобы удалить token/password, сначала нажмите **Отключить**, очистите пароль ссылки в настройках или удалите записи ShareFile из GNOME Passwords and Keys/KWallet. Для отзыва серверного токена используйте **Устройства** в Web UI. Файлы на сервере удаление приложения не затрагивает.
